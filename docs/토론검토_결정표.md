# AI 토론 1·2차 검토 결정표 (2026-11-19)

AI토론실에서 진행한 1차 토론(2026-11-19 10:34, 3자)과 2차 토론(11:12, Gemini가 빠져 2자)을 검토했습니다. 서로 엇갈린 쟁점은 **계획서(팀원공유용 29쪽 4인판) · 실제 KRX 데이터 · 외부 근거** 세 가지와 대조해서, 근거가 더 확실한 쪽을 채택했습니다.

- 판정 근거 종류: **[계획서]** 계획서 조항 · **[데이터]** `data/krx_adjusted.parquet`로 직접 계산 · **[외부]** 법령·논문 · **[계산]** 시간·조합 수 계산
- 결론: **3차 토론은 하지 않습니다.** 남은 쟁점은 숫자를 정하는 일이거나 데이터로 확인할 사실이라 토론으로 풀 수 없습니다. 아래 표로 대체합니다.
- 통합 기준: 이 표의 결정은 [프로젝트 기준](프로젝트_기준.md)에 합쳐졌습니다.
- 상태: 팀장 검토 완료. 다음 회의에서 4명이 확인하고 확정합니다. 확정 전에 바꿀 항목은 회의기록에 남깁니다.

### 2.1 토론에서 다루지 않아 새로 채운 최적화 규칙 (제안값)

1·2차 토론과 이전 토론 4건 모두 "파라미터를 언제·무엇으로 고르는지", "AND 조합의 날짜 기준"을 정하지 않았습니다. 아래 값으로 채웠고 자세한 절차는 [프로젝트 기준 5장](프로젝트_기준.md#5-신호-최적화-방법-이번-프로젝트의-핵심-절차)에 있습니다.

| 항목 | 제안값 | 이유 |
|---|---|---|
| 파라미터 고르기 | 연도별 확장 창(2015~2019), 안정 구간 점수 = 자기+이웃 Edge 중앙값, 동점은 계획서 기본값 | 계획서 STEP 3 "안정 구간"과 STEP 4 연도별 OOS를 그대로 절차로 만든 것 |
| 파라미터 그리드 | 부록 A 범위 안 72세트 (시장별 216회 시도) | 지금 고정해서 결과를 보고 넓히지 못하게 함 |
| AND 날짜 창 | W=3거래일 고정 | 이벤트형 신호는 같은 날만 인정하면 거의 겹치지 않음 |
| 조합 파라미터 | 구성 신호가 각자 고른 값 그대로 (재최적화 없음) | 시도 횟수 폭증 방지 |
| 조합의 자체 매도 | 구성 신호 중 하나라도 매도 신호 | 가장 단순하고 보유를 길게 만들지 않음 |
| S1·S2 그리드 | 손절 4 × 익절 5 = 20세트, ATR n 2·3 | 부록 B 범위 |
| 같은 날 손절·익절 | 손절로 본다 | 일봉으로는 순서를 알 수 없으므로 보수적으로 |
| S4 | 자기 시장 지수 120·200일선 | 부록 B (기존 문서의 "코스피 200일선"은 오기) |
| Edge 대조군 | 같은 날·시장·시총·거래대금 5분위 비신호 종목 평균 | 랜덤 추출의 기댓값과 같아 빠르고 흔들림 없음 |
| t값 | 20거래일 겹치지 않는 블록 | 같은 날 거래끼리 독립이 아님 |
| ML 설정 상한 | 약 18설정 × 확률 기준 3개 | 시도 횟수를 미리 고정 |
| 시험 구간 | 규칙은 2019년 값 고정, ML은 고정 절차로 매년 재학습 | 계획서 4.4 |
